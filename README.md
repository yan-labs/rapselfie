# Rap Selfie

Turn one photo into a short solo AI rap video.

[Visit Rap Selfie](https://rapselfie.com/)

This repository is the official public directory for Rap Selfie. It introduces the website and links to live pages; it is not an independent review. The application source is not published here. A public GitHub listing here does not guarantee search-engine indexing, ranking, or backlink value.

## What it does

Check a photo and preview a still scene in your browser tab before generating. These steps run in the browser without uploading files and need no account. The still preview has no generated motion or audio. For a full video, choose a template or write a custom creative direction, select an available duration and format, and generate. The available model is Seedance 2 Mini; one model is currently available, and source models may differ. If you leave to pay, photos may be saved locally in the browser to restore within 1 hour, as stated on the site. Photos are deleted when rendering finishes or fails.

## Limits and principles

The Guofeng MV template offers a solo rap performance in a Chinese-inspired cinematic setting with Mandarin direction. Custom creative direction replaces the template scene; safety and format rules still apply. You cannot upload your own audio or a reference/multi-reference video. Lyrics, language, lip-sync, and beat timing are requests, not guarantees. Precise lip-sync and Mandarin output are not guaranteed. Full output quality is unverified on the template pages. The service is not affiliated with any artist or label.
